CAFE: Chinese Analytic Frequency Engine

This repository contains the source code and table data for the CAFE text-leveling system.

Files Summary
levelTest.php: The standalone PHP web application featuring a dark-theme/light-gray CSS interface and the exponential difficulty weighting algorithm ($ID^{1.5}$).
  frequency.sql: The database structure and dataset containing the
  3,002 frequency-ranked Chinese characters used to measure student cognitive load.

System Prerequisites
PHP 7.4 or higher
MySQL / MariaDB
